jevで爆速NGワード判定をしよう

入力した文章に不適切な表現が含まれているかを、TypeSafe の判定モデル jev で判定します。
単語の一覧と照らし合わせるのではなく、「暴言か」「脅迫か」「個人を特定できるか」といった12個の質問で、文の中で誰に何が向いているかを見ています。
仕組みは 解説記事 にまとめています。

判定のために文章は TypeSafe の API へ送信されます。実在の人の名前・連絡先・住所などは入力しないでください。

入力

Ctrl+Enter でも判定

判定結果

文章を入力して「判定する」を押すと、ここに項目ごとのスコアが出ます。

判定の流れ

1. 入力を整える

全角・半角の揺れをそろえ、見えない文字を取り除きます。見えない文字を挟んだ伏せ字は、ここで元の語に戻ります。

2. 13問をまとめて聞く

「暴言か」「脅迫か」などの「はい/いいえ」で答える質問12個と、全体の不適切度（0〜3）を1回のリクエストで jev に送ります。jev は全問を並列に評価します。

3. しきい値で二値にする

どれか1項目でもしきい値を超えるか、不適切度が 1.5 以上なら block です。

判定は自動で行われ、誤ることがあります。表示されるスコアは jev が返した「はい」の確率です。 入力した文章と判定結果は、判定の精度を改善するために保存します。 1分あたり10回、全体で1日あたりの回数に上限があります。
